# 三国演义 · 群英谱

一部可读、可查、可玩的三国人物资料站。**699 位人物、1707 条人物关系、六段年表、三方政权制度、143 处地理坐标、89 条历代评语，外加四种解谜玩法。**

站点本体是零框架、零构建、零外链 CDN 的纯静态多页站，断网也能用（Service Worker），微信内置浏览器可直接打开。

- **在线访问**：https://sinclair94.github.io/ROTK/
- **本版定位**：演义本 v0.2，以**毛宗岗评本一百二十回**为据（正史本——《三国志》及裴松之注——仍在整理）

## 本地运行

```sh
python -m http.server 8000
# 打开 http://localhost:8000/
```

推荐用 http 打开——Service Worker 只在 https 或 localhost 下注册。直接双击 `index.html` 也能看全部内容：数据是以 `<script>` 标签注入的、不走 `fetch`，所以 `file://` 下不会报跨域错误，只是没有离线缓存。

## 目录结构

**仓库是扁平的**，站点文件、数据、脚本都放在根目录。原因是本站通过 GitHub 网页上传维护，网页上传会把子目录拍平（`lib/x.js` 传上去变成 `x.js`，相对路径全断），所以不建子目录。

```
*.html              站点页面（8 个板块页 + about.html）
mobile.css          站内样式
wx-compat.css/js    微信内置浏览器适配（视口修正、老内核兜底）
leaflet.css/js      地图库，本地内置，不依赖 CDN
map-svg.js          地图渲染与省级命中判定
data-*.js           全部数据，按主题分片（命名规则见下）
sw.js               Service Worker，由 _ghbuild.js 生成，勿手改
_*.js               构建 / 生成脚本，下划线前缀 = 不参与站点运行
.nojekyll           跳过 Jekyll 处理，保证原始字节不被改写
```

数据分片命名规则：

- `data-wei / shu / wu-qun / more-*.js` — 人物基础数据，按阵营分片
- `data-detail-index.js` + `data-detail-01…15.js` — 事件详解，按人物分片，点开谁才加载谁
- `data-timeline*.js` — 年表（含 `p0` 前史、政治线补丁）
- `data-map*.js` / `data-geo.js` — 地理坐标与边界
- `data-network.js` — 关系网，`_mknet.js` 生成，勿手改
- `data-soup-*.js` / `data-riddles.js` / `data-quotes.js` — 解谜题库

## 技术要点

- **零构建、零框架、零外链 CDN**：字体走系统栈，没有任何 Google Fonts
- **数据以 `<script>` 注入而非 `fetch`**：`file://` 下也能跑
- **事件详解按人物分片 15 份**：点开谁才加载谁，首屏从约 600 KB 降到约 170 KB
- **Service Worker**：页面走网络优先（能拿到新版本），静态资源走缓存优先；跨域请求（高德瓦片）一律不拦截
- **关系网确定性布局**：无随机数、无逐帧动画，算完再渲染，每次打开位置完全一致
- **微信内置浏览器适配**：视口修正、老内核兜底、脚本异常给出可读提示

## 构建与维护

```sh
node _ghbuild.js    # 生成 gh-pages/ 部署目录（含 sw.js、.nojekyll），并做页内引用体检
node _bundle.js     # 打包单文件离线版（约 1.9 MB，供微信传文件 / 断网使用）
node _mknet.js      # 由人物小传 + 年表 + 战役重新生成 data-network.js
```

部署：把 `gh-pages/` 里的文件上传到仓库根目录即可（GitHub Pages 从 `main` 分支根目录发布）。`_ghbuild.js` 会顺带校验每个页面引用的资源是否都存在，缺文件会直接报出来。

## 已知边界

如实列出，不藏着：

- 人物数据按姓名去重后为 697 位（699 条中有 2 处同名重出，未强行合并）
- 生卒年缺史料的一律标注为不详，不做推测填补；关系网问答中统一回退"生卒年不详，无法确知寿数。"
- 演义虚构人物（如貂蝉等）在数据中标出，不与正史人物混同
- 地图为示意性坐标与范围，非历史地理复原
- 关系网由小传、年表、战役文本自动抽取 + 239 条人工校订，仍可能有个别误判
- 正史本（《三国志》及裴松之注）尚未整理
